# Reflection Journal

**Week of:** September 17, 2026

## My goal this week

- Figure out the features I want for PantryPal and start implementing them.
- Think of ways to make the system more fun and creative while keeping it easy to use.

## What I did

- Decided to focus on Filipino recipes and make the interface responsive.
- Worked on ingredient selection, recipe matching, category filtering, and viewing recipe instructions.
- Added a "Surprise me!" feature to help users choose a recipe.
- Set up a collection of 100 recipes and 193 searchable ingredients in Supabase.
- Adjusted the project to follow our professor's template, using Express for the backend.
- Connected the backend to the database and updated the README with setup and usage instructions.

## What blocked me

- I got confused about the folder structure and ended up with duplicate folders.
- The backend could not find the .env file because it was in the wrong location.
- I encountered a database certificate error that prevented the connection from working.
- I initially used Python for the backend before realizing that our professor's template required Express.

## What I learned

- I learned to check the project requirements before choosing the tools and starting development.
- I understand the roles of the frontend, backend, and database more clearly now.
- I learned that file locations and environment settings can affect whether the app runs correctly.
- I learned that a working database connection does not automatically mean the frontend is using it; the frontend must also be configured correctly.
- I realized that documentation is part of development because it helps other people understand and run my project.
